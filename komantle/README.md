# 꼬맨틀 솔버

꼬맨틀 첫 화면의 세 숫자(1위·10위·1,000위 유사도)로 정답을 찾고, 정답은 숨긴 채 입력한 단어보다 더 가까운 단어를 힌트로 보여주는 정적 웹페이지입니다.

- 서버 코드 없음. 모든 계산은 브라우저에서 정적 파일만으로 합니다.
- 외부 API 호출 없음. 꼬맨틀 사이트를 호출하거나 크롤링하지 않습니다. (첫 화면 문장은 사용자가 직접 복사해 붙여넣습니다.)
- 배포: Cloudflare Workers Static Assets (무료 플랜) → https://komantle-solver.mmmn.workers.dev
- 디자인: 메인 사이트와 같은 Halftone 디자인 시스템 (`web/style.css`)
- 원리와 한계 설명: `../docs/솔버-원리.md`

## 폴더 구조

```
komantle/
  data/                secrets.txt, valid_nearest.pkl, komantle_index.npz (git 제외, 아래 1번)
  precompute.py        FastText 벡터 → data/komantle_index.npz (후보별 이웃 1,000개·지문)
  export_web_data.py   npz → web_data/komantle-data/ (fp.bin, n/*.json, meta.json)
  export_vectors.py    단어 벡터 → web_data/komantle-data/{cand.bin, vec/} (단서 대조용)
  web/                 페이지 소스 (index.html, app.js, solver.js, style.css)
  test/                Node 테스트 (1630·1642회차 기준)
  scripts/build.mjs    web/ + web_data/ → dist/ 조립
  wrangler.jsonc       Cloudflare 설정 (정적 자산 전용)
  web_data/, dist/     생성물 (git 제외)
```

## 1. 데이터 준비 (새 PC에서 한 번)

꼬맨틀은 오픈소스(semantle-ko)라 단어 벡터와 정답 후보 목록이 공개돼 있습니다. 그 저장소의 `data/` 폴더에서 두 파일을 `komantle/data/`에 넣습니다.

- `secrets.txt` — 정답 후보 4,650개
- `valid_nearest.pkl` — 어휘 59,118개의 FastText 벡터 (약 140MB)

그다음 `komantle` 폴더에서 순서대로 실행합니다. numpy만 있으면 됩니다.

```
python precompute.py        # 후보 4,650개 × 어휘 59,118개 유사도 → 이웃·지문. 몇 초
python export_web_data.py   # 웹용 지문·이웃 파일
python export_vectors.py    # 웹용 단어 벡터 (float16)
```

`web_data/komantle-data/`에 `fp.bin`, `meta.json`, `n/0.json … n/4649.json`, `cand.bin`, `vec/`가 생깁니다. 약 137MB이며 git에 올리지 않습니다.

## 2. 테스트·로컬 확인

```
cd komantle
npm test        # 로직 테스트 13개 (지문 대조, 단서, 힌트, 벡터 일치)
npm run dev     # dist 조립 후 http://127.0.0.1:8787 에서 확인
```

## 3. 배포

처음 한 번만 Cloudflare 로그인:

```
npx wrangler login
```

이후 배포는 명령 하나:

```
cd komantle
npm run deploy
```

`build`(dist 조립) → `wrangler deploy` 순서로 실행됩니다. 바뀐 파일만 올라가므로 페이지 소스만 고쳤을 때는 몇 초면 끝납니다.

- 배포는 로컬에서만 합니다. 데이터가 git에 없으므로 GitHub 연동 자동 배포는 쓰지 않습니다.
- 데이터 파일은 하루(`max-age=86400`) 캐시되므로 데이터를 다시 만들었을 때는 방문자에게 최대 하루 뒤에 반영됩니다. 페이지 소스(`index.html`, `app.js` 등)는 바로 반영됩니다.

## 4. 사용법

**1. 세 숫자 입력**
- 카드 위의 3단계 안내대로: [꼬맨틀 열기] → 첫 화면 맨 위 문장을 드래그해 복사 → 돌아와서 붙여넣기. 복사할 위치는 카드 안 모형에 표시돼 있습니다.
- 칸에 붙여넣거나 [붙여넣기] 버튼(클립보드 읽기)을 누르면 회차와 세 숫자를 자동으로 읽고 바로 찾습니다. 숫자 세 개만 직접 적어도 됩니다.
- 판정은 1위·10위 유사도로 합니다(오차 0.006). 1,000위는 사이트 어휘 차이로 ±0.1까지 어긋나므로 판정에 쓰지 않고, 후보가 여럿일 때 정렬에만 씁니다.
- "정답 미확정"이 뜨면 **단어 단서**를 펼쳐 꼬맨틀에 이미 친 단어와 그때 나온 유사도를 넣습니다. 어떤 단어든 되고, 두 개면 거의 확정됩니다.

**2. 정답 보기**
- 타이틀바에 "정답 확정 / 미확정" 태그. 버튼을 누르고 확인해야 정답이 보입니다.

**3. 힌트 받기**
- 꼬맨틀에 입력한 단어를 적으면 유사도·순위가 나오고 **순위 막대**가 나타납니다. 1,000위(왼쪽)에서 1위(오른쪽)까지 로그 눈금이고, 마젠타 손잡이를 끌어 힌트를 받을 목표 순위를 정합니다. 기본은 내 순위의 절반. 손잡이 옆에 그 순위의 유사도 미리보기가 보입니다.
- 개수는 3·5·10개 칩 또는 직접 입력(최대 30).
- 받은 힌트는 마젠타 점, 입력한 단어는 흰 점으로 막대에 쌓입니다. [다음 힌트 →]를 누르면 방금 받은 것 중 가장 가까운 단어를 내 단어로 삼아 다시 받습니다.
- 힌트는 항상 내 단어보다 가깝고, 이미 입력한 단어와 정답은 제외됩니다. 이웃 1,000개 밖의 단어는 꼬맨틀에 나온 유사도를 직접 입력합니다.

**순위 구간 보기** (힌트 카드 아래 접이식)
- 정답의 이웃 1,000개를 순위 또는 유사도 구간으로 잘라 먼 쪽 → 가까운 쪽으로 봅니다. 빠른 선택(1,000→500 … 50→10, 내 단어 주변 ±20), 50개씩 더 보기.
- 1~10위는 기본 잠금(■■■). "10위 안 열기"를 눌러야 보입니다. 내 최고 단어보다 앞 구간을 열면 스포일러 경고가 뜹니다. 정답은 목록에 없습니다.

세 숫자, 단서, 입력 기록은 브라우저 `localStorage`에만 저장됩니다. 다른 회차 문장을 붙여넣으면 자동으로 초기화되고, [전체 초기화]로 직접 지울 수도 있습니다.

알려진 차이: 꼬맨틀 서버와 로컬의 어휘 목록이 조금 달라서 순위와 1,000위 유사도는 사이트와 어긋날 수 있습니다(1630회차 29.64/29.54, 1642회차 21.86/21.87). 개별 단어의 유사도는 같은 벡터라 거의 정확하므로, 세 숫자로 안 찾아질 때는 단어 단서가 확실합니다.

꼬맨틀 솔버

서버 없이 브라우저에서만 계산합니다. 입력한 내용은 이 기기에만 저장됩니다.

1. 세 숫자 입력

꼬맨틀 첫 화면 상단 문장의 숫자를 그대로 입력하세요. 문장 전체를 붙여넣어도 됩니다.

단어 단서 (선택 · 세 숫자로 안 찾아질 때)

꼬맨틀에 이미 친 단어와 그때 나온 유사도를 넣으면 훨씬 정확하게 찾습니다. 어떤 단어든 됩니다(유사도가 낮아도 괜찮습니다). 두 개를 넣으면 거의 확실하게 특정됩니다.

2. 정답 보기

스포일러입니다. 버튼을 눌러야 보입니다.

3. 힌트 받기

꼬맨틀에 입력한 단어를 적으면, 그보다 조금 더 유사한 단어를 알려줍니다.

이웃 목록에 없는 단어입니다. 꼬맨틀에 나온 유사도를 입력해주세요.

    입력한 단어

    단어유사도순위

# PRD: 꼬맨틀 솔버

- 작성일: 2026-09-23
- 상태: 프로토타입 배포 완료 (https://komantle-solver.mmmn.workers.dev)
- 소스: `komantle/web/` (index.html, app.js, solver.js, style.css)
- 작성 방식: pm-skills PRD 템플릿(문제 → 목표 → 사용자 → 화면/기능 → 비목표 → 지표) 기준

## 1. 한 줄 요약

꼬맨틀(한국어 단어 유사도 추측 게임)에서 막힌 사용자가 첫 화면의 숫자 3개를 붙여넣으면 정답을 찾고, 자기가 친 단어보다 "조금 더 유사한 단어"를 힌트로 받아 스스로 정답에 도달하게 돕는 정적 웹페이지.

## 2. 문제 정의

- 꼬맨틀은 유사도 점수만 주기 때문에 방향을 못 잡으면 수십 번 추측하다 포기하게 된다.
- 커뮤니티 스포일러는 정답을 바로 알려줘 게임의 재미를 없앤다. "정답은 숨기고 방향만 주는" 도움이 없다.
- 기존 도구는 서버·외부 API·크롤링에 의존해 유지비가 들거나 불안정하다.

## 3. 목표 / 비목표

| 구분 | 내용 |
|---|---|
| 목표 | 정답을 바로 보여주지 않고, 힌트 강도를 골라 스스로 맞히게 한다 (정답은 별도 버튼 뒤에 숨김) |
| 목표 | 서버·외부 API 없이 브라우저만으로 동작, 무료 운영 |
| 목표 | 꼬맨틀 첫 화면 문장을 그대로 붙여넣기만 하면 바로 쓸 수 있다 |
| 비목표 | 로그인, 서버 저장, 랭킹 등 커뮤니티 기능 (입력은 이 기기에만 저장) |
| 비목표 | 꼬맨틀 사이트 자동 연동·크롤링 |

## 4. 대상 사용자

- **주 사용자**: 꼬맨틀을 매일 하지만 30번 넘게 추측해도 방향을 못 잡는 캐주얼 플레이어. 주로 모바일.
- **부 사용자**: 단어 임베딩·유사도 계산에 관심 있는 개발자.

## 5. 화면 구성과 기능 요구사항

페이지는 세로로 쌓인 카드 3개로 구성된다. 헤더에 "서버 없이 브라우저에서만 계산합니다. 입력한 내용은 이 기기에만 저장됩니다."를 표시한다.

|---|---|---|---|

| F1-4 | 단어 단서(접이식): 꼬맨틀에 이미 친 단어 + 유사도를 넣어 후보를 좁힘. 어휘 59,118개 벡터로 브라우저에서 직접 계산. 2개면 거의 확정 | P0 | 완료 |
| F1-5 | 세 숫자가 사이트와 안 맞으면(어휘 차이) 안내 문구를 띄우고 단서 입력을 유도 | P1 | 완료 |

| F2-2 | 스포일러 방지: [정답 보기] 버튼을 눌러야만 정답이 보임. 미확정이면 버튼 비활성 | P0 | 완료 |

## 6. 사용자 흐름

1. 꼬맨틀 첫 화면 상단 문장을 복사해 카드 1의 붙여넣기 칸에 넣는다. 숫자 3개와 회차가 자동으로 채워진다.
2. [찾기]를 누른다. 정확히 맞으면 카드 2·3이 열리고 배지가 "정답 확정"이 된다.
3. 안 맞으면 "정답 미확정"이 되고, 카드 3에 이미 친 단어와 유사도를 2개쯤 넣으면 확정된다.
4. 카드 3에 지금 친 단어를 넣고 강도(조금/보통/많이)를 골라 [힌트]를 누른다. 더 유사한 단어 5개가 나온다.
5. 힌트 단어를 꼬맨틀에 입력하고, 그 결과를 다시 넣으며 정답에 가까워진다. 포기하고 싶을 때만 카드 2의 [정답 보기]를 누른다.

## 7. 디자인 원칙

- 연회색 배경(#f6f7f9) 위 흰색 카드, 12px 둥근 모서리, 최대 폭 720px 단일 컬럼. 모바일 우선.
- 주 버튼 파랑(#1f6feb) 하나, 보조 동작(전체 초기화, 단서 추가, 기록 지우기)은 밑줄 링크 스타일.
- 상태 색: 확정/성공 초록(#15803d), 미확정/경고 주황(#b45309).
- 카드 번호(1·2·3)로 순서를 명시하고, 각 카드 아래 회색 도움말 한 줄로 설명. 카드 2·3은 정답 후보가 생기기 전에는 숨김.
- 스포일러는 항상 버튼 한 번 더 눌러야 보이게 한다.

## 8. 비기능 요구사항

- 서버 코드 없음. 정적 파일만으로 브라우저에서 계산. 입력 상태는 localStorage에만 저장.
- 외부 API·크롤링 없음. 꼬맨틀 사이트에 부하를 주지 않음.
- 데이터 약 135MB(지문·이웃·단어 벡터)는 Cloudflare Workers Static Assets에 배포, 무료 플랜 범위.
- 이웃 데이터는 회차별 JSON을 필요할 때만 받아 첫 로드를 가볍게 유지.
- 로직은 Node 테스트(`npm test`, 1630회차 기준)로 검증.

## 9. 기술 개요

- 프론트: 순수 HTML/JS/CSS (`komantle/web/`), 빌드 도구 없음
- 데이터 생성: Python, FastText 한국어 벡터 → `precompute.py`(이웃·지문) → `export_web_data.py`, `export_vectors.py`
- 배포: Cloudflare Workers (솔버, `npm run deploy`), Vercel (소개 페이지, Next.js 16)

## 10. 성공 지표

| 세 숫자만으로 정답 확정되는 비율 | 70% 이상 (나머지는 단서 2개로 확정) |

| 월 운영 비용 | 0원 |

## 11. 리스크 및 열린 질문

- 꼬맨틀 어휘와 로컬 어휘 차이로 순위가 몇 칸 어긋나거나 세 숫자가 안 맞는 경우가 있다. 단서 입력으로 보완하지만 근본 해결은 아니다.
- 꼬맨틀이 단어 벡터를 바꾸면 사전 계산 데이터를 다시 만들어야 한다.
- 힌트 3단계 기준값(3/4, 1/2, 1/5)은 사용자 피드백으로 조정이 필요하다.
- 과제 요구사항(로그인·CRUD·지도·결제)과 솔버를 어떻게 하나의 서비스로 묶을지 미정. (`docs/PLAN.md` 참고)
